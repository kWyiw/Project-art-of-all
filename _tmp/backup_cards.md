# 卡牌构筑规则书 v1.3

> **本册管什么**：卡牌是什么、怎么装、怎么获得、怎么变强、什么样的一套牌算合法。
> **姐妹文档**：`战斗规则书.md`（一场战斗内部怎么打）、`棋盘层双栏卡槽UI与拖拽交互规格.md`（第 5 章卡槽怎么被"手"操作）
> **上位文档**：`大富翁层规则书.md`（棋盘层）
> **工程说明**：`战斗与卡牌系统规格书.md`（Schema、事件总线、为什么这样设计）
> **数据源**：`第一套卡牌.txt` 是**唯一权威**（33 张）；`卡牌示例.txt` 只作记法说明（见规格书 §13）。
> **冲突时以本册为准**（规则口径）。

**v1.3 变更**（依据玩家裁决）：①新增 **CJ-4.2.1 词条只有一层**——地产、技艺与武器、废料完全对等，都是词条（tag），不存在"大类包含小类"；②自噬之蛇效果改为**必定最大骰**（`MaxRoll` 覆盖，见 `战斗规则书.md` BT-7.7）；③确认数据源为 `第一套卡牌.txt`。

**v1.2 变更**（依据玩家裁决）：①**生命值与护盾都只存在于一场战斗之内**——棋盘层没有生命值，护盾战斗结束即消失。因此任何"永久护盾""下场战斗继承护盾"的设计都必须单独裁决（CJ-3.3）；②**淡水走方案 C**：删除"出售时价值+1"，淡水改为纯资源燃料（CJ-6.9）。

**v1.1 变更**（依据玩家裁决）：①**出售后卡牌永久消失**（CJ-6.5、CJ-6.7），所有"卖—买—卖"循环被从根上取消；②**"回合"只指棋盘层回合**（CJ-1.5）。

**本版不含**（已明确暂缓）：卡牌合成 / 升级 / 改造系统、过载（过热）机制。

## 第 1 章 总则

**CJ-1.1　这个游戏没有手牌。**
没有抽牌、没有洗牌、没有弃牌堆、没有"每回合抽 5 张"。玩家拥有的每一张牌都在手里，随时可以看、随时可以调顺序。

**CJ-1.2　卡牌是永久资产，不是消耗品。**
一张牌买下来就一直在。它只会在两种情况下离开你：**你主动卖了它（卖掉即消失）**，或者被效果永久摧毁（目前只有粉碎机）。

**CJ-1.3　卡牌的强势来自两处：牌本身，和它的位置。**
同一套牌换个顺序就是另一套牌。**位置是构筑的一部分**，不是摆放细节。所以重排永远是免费的、随时可做的。

**CJ-1.4　卡牌没有稀有度。**
本版不引入稀有度系统。强弱由价差、尺寸、词条决定。商店的随机性是唯一的"获取运气"。

**CJ-1.5　全书的"回合"只有一个含义：大富翁棋盘层的回合。**
也就是"从当前玩家开始行动，到下一个玩家开始行动"这一整段时间。战斗内部**没有回合**（那里面只有 tick），所以：

| 卡面写法 | 在哪结算 | 每场战斗最多触发 |
|---|---|---|
| 每回合结束… | 棋盘层，该玩家回合结束时 | 0 次 |
| 每次行动后… | 棋盘层，该玩家完成一次移动/事件后 | 0 次 |
| 战斗中… / 每次施法… | 战斗层 | 按 CD |
| 出售时… | 棋盘层，卖出那张牌的瞬间 | — |

> **这条要写进 UI**：卡面上凡是带"回合"的字样，都应该配一个棋盘图标；带"战斗"的配一个剑图标。否则玩家会以为草场在战斗里也每回合给钱。

## 第 2 章 卡牌的构成

**CJ-2.1　每张卡有且只有以下字段。**

| 字段 | 含义 | 约束 |
|---|---|---|
| 名称 | 唯一标识 | 全库唯一 |
| 尺寸（c） | 占几个卡槽 | 1 / 2 / 3 |
| 冷却（s） | 两次主动施法的间隔 | 无冷却 = 纯被动牌 |
| 骰（XDY） | 施法时的骰池 | 无骰 = 不产生数值 |
| 词条 | 分类标签，可多个 | 见第 4 章 |
| 价值（g） | 卡的售价与"X"的来源 | ≥ 0，整数 |
| 效果行 | 1 条或多条 | 见第 3 章 |

**CJ-2.2　统一记法**

```
名称  Xc  Ys  [词条…]  Zg
```

例：

```
撬棍    1c  3s   武器      1g
汽车门板 2c  9s   工具      4g
双持    1c  —    武器·技艺  1g
```

—— 破折号（—）表示无冷却，即纯被动牌。

**CJ-2.3　尺寸决定基准价。**

| 尺寸 | 基准价值 |
|---|---|
| 1c | 1g |
| 2c | 2g |
| 3c | 4g |

**卡牌的实际价值可以偏离基准价**（由效果或永久成长改写），但**新卡的初始价值必须等于基准价**，除非该卡的效果行明写了"价值 X"。

> **为什么 3c 是 4g 而不是 3g**：尺寸线性占格、但三格连排会牺牲相邻位，边际成本更高。4g 让"3c 的大牌"成为"贵但强"的定位，而不是"线性但鸡肋"。

## 第 3 章 效果行的记法

**CJ-3.1　每条效果行必须能被拆成四个部分。**

```
[触发条件]          [动作]              [目标]        [数值]
每与一张废料相邻   →  多重释放 +1      →  自身      →  数量 1
每次触发缓速       →  获得护盾         →  我方      →  1D6
战斗开始时         →  摧毁             →  背包最左侧废料 → 1 张
```

**CJ-3.2　四个部分各自的合法取值（按此清单实现，不允许自由文本）。**

| 触发条件 | |
|---|---|
| 施法时（主动牌的默认触发） | |
| 战斗开始时 / 战斗结束时 | |
| 每回合结束时 | 棋盘层回合 |
| 每次造成伤害 / 灼烧 / 中毒 | 事件触发 |
| 每次获得护盾 / 治疗 | 事件触发 |
| 每次触发缓速 / 加速 / 充能 | 事件触发 |
| 我方使用某词条的牌时 | |
| 被击倒时 | |
| 出售时 | 棋盘层 |
| 永久（常驻） | 光环或被动 |

| 动作 | |
|---|---|
| 造成伤害 | 可附带"无视护盾" |
| 施加 中毒 / 灼烧 / 再生 | |
| 获得护盾 / 治疗 | 仅本场战斗内有效 |
| 施加 缓速 / 加速 / 充能 | |
| 多重释放 | 对自身或目标 |
| 摧毁 | 见战斗规则书 BT-8 |
| 修改骰值 / 骰数 | 修正与数量的区别见战斗规则书 BT-6.1 |
| 改写价值 | |
| 生成卡牌 | 棋盘层 |
| 充能 / 加速 / 缓速 | |

| 目标 | |
|---|---|
| 自身 / 左邻 / 右邻 / 全部相邻 | |
| 我方全部 / 对方全部 | |
| 对方随机 N 张 | |
| 按词条筛选 | 例"对方所有工具" |
| 背包指定位置 | 例"最左侧废料" |

**CJ-3.3　作用域铁律：生命与护盾只活在一场战斗里。**

> **玩家裁决**：生命值只在战斗里用，棋盘层没有生命值，护盾仅在本场战斗生效。护盾在战斗结束的那一刻随战斗一起消失——不跨战斗、不带进棋盘层、不变成"永久护盾"类被动。**任何以"下一场战斗开始时继承护盾"为核心的设计都要单独裁决**（例如 `大富翁层规则书.md` §4.2.1 的「蓄势格」提案），不能默认允许。

**CJ-3.4　数值表达式只有四种。**

| 形式 | 例 | 说明 |
|---|---|---|
| 常量 | `3` | |
| 骰 | `1D6`、`2D20` | 每枚骰独立取值独立修正 |
| 价值倍率 | `X d4` | X = 这张牌当前的价值 |
| 计数 | `每与一张废料相邻` | 由求值环境提供 |

**CJ-3.5　效果行分三类，必须显式标注。**

| 类型 | 特征 | 例 |
|---|---|---|
| 主动 | 有冷却，冷却归零时开火 | 撬棍 |
| 被动 | 无冷却，某事件发生时触发 | 胶带、特种橡胶、小汪 |
| 光环 | 无冷却，持续改写其他牌的参数 | 磨刀石、回收站、双持、自噬之蛇 |

**主动牌也可以同时带被动**（塑料棚：主动缓速 + 被动获盾）。这是允许的，也是好的设计。

## 第 4 章 词条全集

**CJ-4.1　词条共 9 种，一张牌可以有多个。**

| 词条 | 定义 | 读法 |
|---|---|---|
| **武器** | 能造成伤害的牌 | "加强武器"只影响这类 |
| **工具** | 影响时间轴或其他牌的支援牌（充能、加速、护盾、缓速） | 凡改"节奏"的多数是工具 |
| **废料** | 低质材料。本身可用，但主要价值是被消耗或被利用率 | 火堆、回收站、粉碎机的燃料 |
| **食物** | 治疗与辅助 | 触发"使用食物"类被动 |
| **伙伴** | 有独立意志/独立数值的牌 | 通常 CD 长、单体强 |
| **陷阱** | 出售时在棋盘留下后手 | 战斗侧通常也有用（铁丝网） |
| **地产** | 资源循环类：生成、回收、转化 | 承载"回合结束""战斗开始"这类周期触发 |
| **技艺** | 只改变其他牌的属性，自己不产生战斗动作 | 必然是纯被动或光环 |
| **资源** | 0 价值消耗品，靠出售/生成流转 | 淡水 |

**CJ-4.2　词条不是装饰，它是光环的作用面。**
所以**新卡必须至少有一个词条**，且词条的判定标准是"这张牌在光环查询时应该被谁选中"。

**CJ-4.2.1　词条只有一层，没有第二层分类。（玩家裁决）**
**地产、技艺与武器、废料是完全对等的词条**——它们是标签（tag），既不是地块类型，也不是卡牌大类、不是稀有度、不是类别树。
因此 `粉碎机 3c 地产·武器` 是合法的：它同时落在"地产"与"武器"两个光环作用面上，任何查询"地产"或"武器"的光环都会选中它，两处都生效。
**推论**：不要写"地产牌"这种说法去暗示它属于某个更高层级——它就是"带地产词条的牌"。

> **为什么"地产"要按"资源循环"定义**：现有三张地产牌（回收站=废料变现、雪水净化器=生成淡水、粉碎机=废料换成长）的共同点是**把一种资源转成另一种**。它们也都恰好需要周期触发（回合结束/战斗开始），因为"循环"本身就是周期性的。按这个定义，未来加"地产"牌时判断标准很清晰：**它是不是在做资源转化？**

**CJ-4.3　"技艺"是唯一自带限制的词条：不能有主动效果。**
它只能是被动或光环。若一张技艺牌被写上了主动伤害，它应该被改成武器。
（"技艺"不是"规则卡"的同义词——它是词条，与武器同层；`双持 1c 武器·技艺` 只是一张同时带两个词条的被动牌。）

## 第 5 章 卡槽与摆放

### 5.1 两个区域

**CJ-5.1　每个玩家有两个卡牌区域。**

| 区域 | 宽度 | 作用 |
|---|---|---|
| **背包** | 固定 10c | 存放所有卡牌；只有被动与光环生效 |
| **战斗栏** | 随等级解锁，见下表 | 战斗中真正出手的序列 |

**CJ-5.2　战斗栏宽度按等级解锁。**

| 等级 | 战斗栏宽度 |
|---|---|
| 1 | 4c |
| 2 | 6c |
| 3 | 8c |
| 4 | 10c |
| 5 | 10c |

背包固定 10c，所以 4 级之后"背包 = 战斗栏"，全部牌都能上场。

**CJ-5.3　一张牌要么在背包、要么在战斗栏，不能同时在两处。**
例外是标了 `BagAndBattle` 的牌——它们**在背包里也生效**（草场、回收站这类理财牌）。这是**词条级属性**，不是每张牌单独开关。

**CJ-5.4　三个区域属性**

| 属性 | 含义 | 例 |
|---|---|---|
| `BattleOnly` | 只在战斗栏生效 | 撬棍 |
| `BagOnly` | 只在背包生效 | 幸运饼干 |
| `BagAndBattle` | 两处都生效 | 草场、回收站 |

**默认是 `BattleOnly`。** 只有明写"在背包中也生效"的才是 `BagAndBattle`。

### 5.2 摆放规则

**CJ-5.5　战斗栏是一维序列，从左到右有顺序。**
"相邻"= 左右紧挨（见战斗规则书 BT-7.4），"触发顺序"= 从左到右（BT-3.10）。

**CJ-5.6　重排免费、无限次、不受回合限制。**
只要不在战斗中就随时可以拖。

> 拖拽的具体交互（阈值、插入式落位、非法反馈、跨栏、常驻档位）见 `棋盘层双栏卡槽UI与拖拽交互规格.md` 第 3、5 章；**出售**的入口见其第 4 章：拖进**专用出售区**松手即卖，无确认无撤销，拖出区外回弹。

**CJ-5.7　战斗栏必须在开战瞬间合法。**
合法性见第 9 章。战斗中不可变更阵容。

**CJ-5.8　允许留空槽。**
你有 10c 的战斗栏但只放了 3c，剩下的 7c 空着——合法，但显然浪费。

**CJ-5.9　允许持有同名卡的多份。**
"两张撬棍"是合法的，占 2c。唯一的限制是背包总宽度。

**CJ-5.10　战斗栏里的牌在战斗结束后回到背包，位置不变。**
被打掉的牌（本场被摧毁）也回来。只有永久摧毁例外（战斗规则书 BT-8.2）。

## 第 6 章 获得与失去

### 6.1 获得

**CJ-6.1　获得卡牌只有四种途径。**

| 途径 | 规则 |
|---|---|
| **商店** | 走上商店格即进入。每次 3 张候选，可用 2 碎片重掷 1 次（每回合每店限 1 次） |
| **奖励格** | 免费二选一，无需付钱 |
| **生成** | 回合结束类效果产出（雪水净化器 → 淡水） |
| **起始牌组** | 开局自带，见 CJ-11 |

**CJ-6.2　购买前必须通过背包宽度校验。**
想买的牌尺寸 > 背包剩余宽度时，购买按钮禁用，并提示需要先卖掉多少 c。

**CJ-6.3　商店的候选池按"当前局面"加权，不是纯均匀随机。**
这就是许多同类游戏的"动态卡池"。本版规则只约束结果：**任何一张牌在一局内被抽到的概率必须 > 0，且不得因为你已持有某张牌就完全屏蔽它**（否则"堆同名牌"的构筑会被系统悄悄禁掉）。

**CJ-6.4　生成的卡牌若背包放不下，则生成失败并提示。**
不排队、不延时、不自动替换。

### 6.2 失去

**CJ-6.5　出售是唯一的主动放弃方式。出售后这张牌就没了。**
出售不耗回合、不限次数、不限位置。卖出去的那一刻，**该牌永久离开你的牌组**——不回到商店、不进弃牌堆、不能买回同一张。想要同样的牌只能重新买或重新获得一张新的。

**CJ-6.6　出售价格 = 该牌当前价值。**
价值可以是买价，也可以是成长后的价（铜锣烧、回收站光环）。

**CJ-6.7　"出售时"类效果在卖出那一刻结算一次，然后该牌消失。**
铁丝网（留陷阱）、车票（回 home）、敲诈（留陷阱）都是"出售时"。

> **因为牌卖出去就消失，"出售时"效果是这张牌留给你的最后一份产出**——它是"卖掉一张牌"这个动作的附加收益，而不是让你反复买卖的引擎。这也让"卖牌"成为一个真正的取舍：你换到的是一次性收益，失去的是牌本身。
> 顺带，所有"卖—买—卖"刷钱的可能性被这条规则**从根上堵死**了：没有牌能卖第二次。

**CJ-6.8　永久摧毁的牌不可恢复。**（当前只有粉碎机的目标）

**CJ-6.9　淡水：原"出售时价值+1"已删除（玩家裁决，方案 C）。**
原因：CJ-6.5 规定牌卖掉即永久消失，"出售时价值+1"提升的是一个永远用不上的数字。

**淡水现在的定位：1c / 0g / 无冷却的资源牌**——它是**燃料、相邻素材、触发源**，靠被消耗和被利用产生价值，自身不再成长。

> 这条决定同时关掉了一个隐患：任何"卖得越多越值钱"的牌，在"卖掉即消失"下都只能改成"造得越多越值钱"（方案 A），否则就会出现"这张牌存在的意义就是被卖"，而卖掉之后它又不存在了——**逻辑上自相矛盾**。淡水直接走"纯资源"路线最干净。

## 第 7 章 价值

**CJ-7.1　价值有三个用途，且只有这三个。**

| 用途 | 说明 |
|---|---|
| 售价 | 卖出时得到的金币/碎片 |
| 数值来源 | 卡面写 `X d4` 时 X = 价值 |
| 光环判定 | 回收站"废料价值按尺寸 +1/+2/+3" |

**CJ-7.2　价值可以是 0，不能是负数。**
0 价值的牌（淡水）卖不出钱，但可以当燃料、当相邻、当触发源。

**CJ-7.3　价值的变化分两种作用域。**
- **本场战斗内**：临时，战斗结束复原
- **本局内**：写存档，永久保留（铜锣烧每回合 +1）

> **没有第三种"出售时的价值"**——因为牌卖出去就消失了（CJ-6.5），任何"出售时价值 +N"的效果都无从生效。见 CJ-6.9。

**CJ-7.4　售价永远 ≤ 该牌的购买价。**
若有光环或效果让售价超过买价，**超出部分被截断**。

> **这条是防套利的地板规则**：回收站给废料 +1 价值，如果没有这条，"买废料 → 回收站抬价 → 卖掉"就是一台印钞机。**"卖出去就没了"（CJ-6.5）已经堵掉了无限循环**，但一次性的稳赚仍然存在（买 2 金卖 3 金），所以这条地板规则保留。截断之后，回收站的价值体现在**战斗中**（废料牌自己变强），而不是在账面上。

## 第 8 章 永久成长

**CJ-8.1　永久成长是局内（RunScope）修正，必须写存档。**

**CJ-8.2　成长有上限，防止一张牌滚成神。**

| 项 | 上限 |
|---|---|
| 单张牌的骰值修正 | −5 ~ +5 |
| 单张牌的骰数修正 | −2 ~ +4 |
| 单张牌的价值 | 0 ~ 20 |

**CJ-8.3　达到上限后，新的成长尝试静默失败**（不报错、不浪费资源、不显示动画）。

**CJ-8.4　允许的成长源（本版全部）**

| 来源 | 成长内容 | 作用域 |
|---|---|---|
| 粉碎机 | 骰数永久 +1（代价：摧毁一张废料） | 局内 |
| 幸运饼干 | 永久修正 | 局内 |
| 铜锣烧 | 每回合结束价值 +1 | 局内 |
| ~~淡水~~ | ~~出售时价值 +1~~ → **已删除（CJ-6.9 方案 C）** | — |
| 回收站（光环） | 废料价值 +1/+2/+3 | 实时，不写档 |

**CJ-8.5　成长不是无限的。**
上表每一行都必须能被玩家看见——**卡面上要显示当前值和上限**，否则玩家不知道自己在滚雪球还是在浪费。

## 第 9 章 构筑合法性校验

**CJ-9.1　一套牌（背包 + 战斗栏）在进入战斗前必须同时通过以下校验。**

| # | 校验项 | 失败处理 |
|---|---|---|
| 1 | 背包总尺寸 ≤ 10c | 禁止操作 |
| 2 | 战斗栏总尺寸 ≤ 当前等级宽度 | 开战按钮禁用 |
| 3 | 每张牌尺寸 ∈ {1,2,3} | 加载期报错 |
| 4 | 每张牌至少 1 个词条 | 加载期报错 |
| 5 | 每张牌的冷却 ≥ 0 且为整数秒 | 加载期报错 |
| 6 | 效果行能解析成第 3 章的四个部分 | 加载期报错 |
| 7 | 光环依赖图无环 | 加载期报错 |
| 8 | 新卡初始价值 = 尺寸基准价（除非明写价值） | 加载期报错 |
| 9 | 每张牌的售价 ≤ 购买价 | 运行时截断 |

**CJ-9.2　第 3~8 项是"数据加载期"错误，第 1、2、9 项是"运行时"规则。**
加载期错误会让整份卡表拒绝加载——**这比在战斗中崩掉好**。

**CJ-9.3　数据校验必须有一张"坏卡表"测试集。**
故意写 8 张坏卡（超尺寸、无词条、负冷却、光环成环、效果行写不成四段、初始价值错、售价套利、词条不合法），断言加载器逐条拒绝并且报出卡名。

## 第 12 章 新增一张卡的填写模板

新增卡必须填满这张表才能入库。

```
名称：      撬棍
尺寸：      1c
冷却：      180 tick（3s）
词条：      武器, BattleOnly
初始价值：  1g（= 1c 基准价）
骰：        1D6

效果行 1：
  触发：    施法时
  动作：    造成伤害（不无视护盾）
  目标：    对方
  数值：    1D6
```

**填写时的三个必答问题：**

1. **它在哪？** BattleOnly / BagOnly / BagAndBattle？
2. **它和谁联动？** 有词条就会被某些光环选中——它想被选中吗？
3. **它的每槽效率是多少？** 单次数值 × 每 20 秒触发次数 ÷ 尺寸（20 秒 = 不吃超时惩罚的自然战斗窗口）。低于 0.9 的牌需要有明确的联动理由才能存在。

## 附录 B　与棋盘层的接口

| 时机 | 方向 | 内容 |
|---|---|---|
| 走上商店格 | 棋盘 → 构筑 | 开启商店，给出 3 张候选 |
| 回合结束 | 棋盘 → 构筑 | 触发"每回合结束"类效果（草场、铜锣烧、雪水净化器） |
| 出售 | 构筑 → 棋盘 | 触发"出售时"类效果（车票、铁丝网、敲诈、淡水） |
| 开战 | 构筑 → 战斗 | 战斗栏快照 + 局内永久修正 |
| 升级 | 棋盘 → 构筑 | 解锁战斗栏宽度 |

> **构筑层不持有任何棋盘状态。** 它与棋盘层只通过上表这几个明确时机交互。
