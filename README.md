# 〇、基础设定
## 1.项目名称：Project-art-fo-all
## 2.游戏类型：带有回合制棋盘牌组构建策略要素的四人联机派对游戏（先实现用CPU取代另外三位玩家的单人模式）
# 一、游戏设定
## 1.基础设定
# ·南极战争
  发生在很久之前的世界战争，间接导致了独立探险联盟的成立。
# ·人类艺术馆
  人类建造在南极的巨大圆环形建筑，出于某种原因内部出现了某种异变，目前处于废弃状态。
# ·失落珍宝
  由独立探险联盟划定的一份名单，其上的内容主要是在南极战争之后消失在公共视野中的画作、雕塑等艺术品，有人会出高价收购，哪怕是赝品。
# ·独立探险联盟
  南极战争发生后逐渐兴起的世界探险组织，组织成员热衷于探索世界上的各种废弃人造设施，并以兜售失落珍宝谋生。
## 2.故事背景
故事发生在人类文明消失前夕，主角（暂命名“容器”）作为独立探险家来到南极“人类艺术博物馆/人类艺术馆”，找寻失落珍宝。当主角进入这座巨大的圆环状建筑时，他只看到了一条空旷的环形走廊以及放置在墙壁上的铭牌标识，所有的艺术品都不翼而飞。思考之际，主角来到圆环中央的庭院，在庭院中央的纪念碑周围，竟凭空出现了一个酷似大富翁结构的巨大棋盘，原来在主角踏入庭院的时候，他就已经加入了这场“要么一无所有，要么带走馆藏离开”的棋局。
# 二、玩法系统
## 0.名词解释
### ·画廊
  位于准备房间的展示区域，是一条空旷的环形走廊，其墙壁上放置有铭牌标识，所有的艺术品都不翼而飞。
### ·地块
  地块是指人物所在的区域，同个地块上可以存在多个人物。地块是离散的，多个地块可以同时附加一个效果，此时将他们视为同一个地块。
### ·珍宝
  珍宝是指游戏中玩家可以在地块和商店中可以获得的手牌，珍宝可以同时拥有多数个，但是只能同时装配少数个。
### ·珍宝碎片
  游戏中经济系统的基础货币，珍宝碎片可以由玩家手中珍宝销毁获得，部分珍宝销毁时可以对一定个地块造成一定效果。
### ·珍宝CD
  每个珍宝都有自己的独立CD，CD只在战斗中生效。
### ·装配栏
  玩家可以在战斗开始之前的任意时候将珍宝放置在装配栏中

## 1.准备房间
玩家会出生在一条弧形走廊里，这条走廊就是准备房间，在准备房间中玩家可以以第一人称视角自由移动。
## 2.类大富翁玩法
在准备房间中玩家可以进入游戏的主要玩法，该玩法以大富翁为玩法基底，在一张由多种地块组成的循环交错的地图上，四个玩家轮流按骰子的点数前进数个地块。率先升到六级的玩家获胜（在单机模式中，场上将始终存在一个玩家和三个npc，只有玩家可以获胜）。升级有两种方式，一种是积攒珍宝碎片，一种是攒胜利场次。
玩家走到奖励地块会获得卡牌，走到怪物地块会进入战斗，走到商店地块可消耗金币购买卡牌，走到传送地块会随机传送到其他传送地块。每个玩家都有自己的home地块，经过自己的home地块时可选择留下。

　　每过一段时间所有玩家获得定量金币。

　　玩家经过其他玩家时可选择留在此地块与之战斗。胜者会抢夺败者的金币和胜场。
### 地块介绍

 1.基础地块
 
 玩家可以经过的地块，没有附加效果。所有下述特殊地块的实现都由基础地块+其上的效果附加实现。
 
 2.奖励地块
 
 玩家走到奖励地块会从随机2张珍宝选择其一，奖励地块固定在指定地块。
 
 3.npc地块
 
 npc地块由基础地块+其上的npc构成，npc和玩家遵循一样的移动逻辑进行移动。玩家路过npc地块可选择留下。当玩家停在npc地块时会触发应战。
 
 4.商店地块
 
 商店地块由商人立牌+基础地块构成。玩家走到商店地块可以消耗珍宝碎片购买卡牌，也可以与商店库存等价交换珍宝。商店地块固定在指定地块。玩家每次停在商店地块，商店会刷新并上架三张珍宝，根据珍宝的大小1c/2c/3c按2g/4g/8g的价格售卖，每次进入商店玩家有一次花费2g刷新在售的珍宝的机会。
 
 5.传送地块
 
 传送地块由传送门+基础地块构成。停留在传送地块上会将角色随机传送至其他传送地块上。
 
 6.home地块
 
 每个玩家都有自己的出生地块作为home地块，出生时默认为0级，第一次投骰子之前会强制升到1级。经过任意的的home地块时可以选择留下并消耗一定的珍宝碎片或者胜利次数进行升级，每次升级之后需要选择下一次的升级方式。
 
 
## 3.战斗系统
战斗系统由珍宝装配构建+D骰子+独立CD自动战斗构成，较轻量化。参考游戏《背包乱斗》和《大巴扎》的战斗系统。
### 珍宝装配
在类大富翁棋盘下方的装配栏中（分为共10格的背包栏位和随等级提升1/2/3/4/5级逐渐扩张4/6/8/10/10格的战斗栏位），玩家可以从背包中拿取珍宝进行装配，每个珍宝都有一定的宽度，简称c。珍宝共分为1c/2c/3c三类。
### D骰子
部分珍宝有随机点数部分，例如：
> 打火机 1c 5s 造成1D4灼烧

其中1D4时指在每次释放前随机在1/2/3/4中选择一个值并造成相应的伤害。
### 人物HP
战斗中人物具有生命值，生命值耗尽时战斗结束。生命值随等级提升，1/2/3/4/5级对应100/150/200/250/300最大生命值。
### 应战
战斗胜利后玩家会获得1点胜利次数且夺取对方30%珍宝碎片。战斗失败后玩家会失去1点胜利次数且失去30%珍宝碎片，并且会返回home地块。
