# 艺术史游戏设计  
## 〇、基础设定
暂定项目名称:Project-art-of-all  
游戏类型:**多人回合制棋盘策略牌组构筑游戏**
## 一、游戏背景  
1.故事设定  
故事发生在人类文明消失前夕，主角（暂命名“容器”）作为独立探险家来到南极“人类艺术博物馆/人类艺术馆”，找寻传说中的世界名画《蒙娜丽莎的微笑》（或者任意其他的，这个可以改）。当主角进入这座巨大的圆环状建筑时，他只看到了一条空旷的环形走廊以及放置在墙壁上的铭牌标识，所有的艺术品都不翼而飞。思考之际，主角来到圆环中央的庭院，在庭院中央的纪念碑周围，竟凭空出现了一个酷似大富翁结构的巨大棋盘，原来在主角踏入庭院的时候，他就已经加入了这场“要么死掉，要么带走馆藏离开”的殊死战斗。  
## 二、玩法系统  
### 1.类大富翁基础玩法  
以大富翁为玩法基底，在一张由多种地块组成的循环交错的地图上，四个玩家（可选人机）轮流按骰子的点数前进步数。  
率先升到六级的玩家获胜。升级有两种方式，一种是攒金币，一种是攒胜利场次。  
每过一段时间所有玩家获得定量金币。  
### 2.地块介绍  
1.基础地块  
可以经过的地块，没有附加效果，玩家可通过消耗卡牌改变地块效果。  
2.奖励地块  
玩家走到奖励地块会获得卡牌或金币，奖励地块不会移动，每x轮进行随机刷新。  
3.怪物地块  
怪物地块由基础地块+其上的怪物组成，怪物和玩家遵循一样的移动逻辑进行移动。当玩家走到怪物地块会触发应战/逃跑，逃跑会随机没收玩家的一定卡牌，扣除一定生命值和cost，应战胜利后会获得升级机会且随机奖励一些金币。  
4.商店地块  
玩家走到商店地块可消耗金币或下次战斗的cost购买卡牌和一般道具，也可以通过出售卡牌获取金币，一般道具可以改变任意指定地块的效果（通常不包括home地块），商店系统暂不展开讨论。  
5.传送地块  
传送地块由临时传送门+基础地块构成，临时传送门会在开局时固定生成在一些格子上，持续xx回合后移动到其他的固定位置。传送门的触发效果是随机传送到里画廊的位置，里画廊里有特殊消耗卡牌“名画碎片”（属性固定，无详细介绍，有效果提示）玩家可以选择一张名画碎片应用于战斗系统或者触发特殊事件。  
6.home地块  
每个玩家都有自己的出生地块作为home地块，经过自己的home地块时可选择留下。玩家攒到足够升级的金币/胜场后到达任意home地块即可升级并决定自己下次升级的方式。当升级到最高等级后，玩家可以选择在非自己home地块结束游戏（通常结局），也可以选择在自己的home地块结束游戏（特殊结局）。  
7.玩家遭遇战  
玩家经过其他玩家时可选择留在此地块与之战斗。胜者会抢夺败者的一定金币和1胜场次数。  
## 三、场景构建  
1.人类艺术馆  
巨大的圆环状建筑，由走廊+内部庭院组成，表走廊内只有放置在墙壁上的铭牌标识，所有的艺术品都不翼而飞。里走廊内只有悬浮在墙壁附近的名画碎片。  
内部庭院中央有一根圆柱状纪念碑，细节待定。纪念碑周围是大富翁玩法的棋盘。

## 四、卡牌，道具及战斗系统详解

### 1.卡牌系统**  
卡牌是推进游戏进程的核心，以牌组构筑作为卡牌装备系统，既有战斗用的卡牌，又有理财用的卡牌。玩家有10个背包卡牌栏，随等级提升还有4/6/8/10个战斗卡牌栏。所有卡牌都有售价，玩家在商店中可以出售自己的卡牌。  
### 2.道具系统**  
道具分为一般道具和特殊道具，任何道具都是消耗道具，具有一定的使用次数。  
### 3.战斗系统  
卡牌构建+D骰子+自动战斗  
在类大富翁基础玩法的中玩家可以自由的获取销毁和调整自己手中的卡牌套组，达成各种组合效果，当遭遇战斗事件的时候选择应战则会进入战斗界面，进行自动战斗。
