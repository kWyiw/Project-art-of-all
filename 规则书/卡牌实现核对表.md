# 卡牌实现核对表

> 对照对象：`卡牌设计稿/第一套卡牌.txt`（唯一权威）。
> 口径：设计稿写「1d4/1d6」的，斜杠前是基础版、斜杠后是升级版（CJ-5.11）。
> 「实现」一列写的是**代码里的实际行为**，不是悬停窗里的设计稿原文；有差异的会在「状态」里写清楚。
> 设计稿里整行以「（」开头的括注是写给实现者的解释（举例、规则示例、词条补充），
> 玩家在悬停窗里看不到它们（`CardDesignText.Lines` 滤掉，`RawLines` 保留原文）。
> 棋盘层（战斗外成长）的效果由 `Assets/Game/Core/Match/BoardCardEconomy.cs` 结算，
> 战斗内的效果是 `Assets/Game/Core/Cards/CardDatabase.cs` 里的数据。

## 通用口径

| 项 | 规则 |
|---|---|
| 价值阶梯 | 1c = 1g、2c = 2g、3c = 4g（`卡牌示例.txt`）；铜锣烧 1g、淡水 0g、神秘饮料 8g |
| 冷却 | 设计稿的秒数 × 60 tick；升级版只写变了的冷却 |
| 修正 | 骰面修正夹在 `[1, 骰面]`（`EffectAmount.Roll`），所以「+100」不能用骰面修正表达，见自噬之蛇 |
| 棋盘层 | 售卖、成长、产牌、陷阱都在棋盘层按基础牌 id 结算，不进战斗数据；悬停窗由 `CardText.BoardNote` 补一句（卡面不写效果） |

## 已知差异清单（需要玩家知道的）

1. **自噬之蛇的 +100 是「结算后平加」**，不是骰面修正。骰面修正会被夹到 1..骰面，所以设计稿的「所有数值 +100」只能这样实现；悬停窗文案（设计稿原文）读作「右侧相邻牌的数值+100」。
2. **特种橡胶的护盾 +1/+2 是「该方获得格挡时 +1/+2」**，不区分格挡来自哪张牌；因为格挡只可能来自护盾牌，结论与设计稿的「所有护盾牌 +1」相同。
3. **棋盘层效果不在战斗数据里**：粉碎机成长、雪水净化器产淡水、回收站卖价加成、铜锣烧/黄金战车价值成长、幸运饼干/淡水的永久修正、铁丝网/路障的陷阱，都由 `BoardCardEconomy` 与 `MatchController` 结算；悬停窗用 `CardText.BoardNote` 补一句说明（卡面不写效果）。
4. **幸运饼干的数据里有一条永不触发的 `CardSold` 被动**：`CardDefinition` 要求每张牌至少有一个效果，而它的真实效果在棋盘层；悬停窗文案会跳过 `CardSold` 被动，改由 `BoardNote` 描述。
